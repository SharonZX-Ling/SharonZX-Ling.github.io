## 修复移动端 Bilibili 视频自动播放 Bug
- 问题：手机端打开网页时，Internship 叠纸实习的 Bilibili 视频自动播放（含声音）
- 根因：页面加载时立即渲染 Bilibili iframe（即使 accordion 折叠），iframe allow 含 autoplay，移动端 Bilibili 播放器自动播放
- 修复方案（js/main.js）：
  1. 懒加载媒体：accordion 展开时才渲染 iframe/video，收起时清除 DOM 停止播放
  2. iframe allow 移除 autoplay → 改为 `encrypted-media; fullscreen`
  3. Bilibili URL 追加 `&autoplay=0` 参数
  4. Feature Showcase 视频改为懒加载（点击时才设 src），默认 muted=true，用户点击播放后取消静音
  5. Feature 视频 preload 改为 none（原为 metadata）
