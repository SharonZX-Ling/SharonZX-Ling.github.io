## 修复移动端 Bilibili 视频自动播放 Bug
- 问题：手机端打开网页时，Internship 叠纸实习的 Bilibili 视频自动播放（含声音）
- 根因：页面加载时立即渲染 Bilibili iframe（即使 accordion 折叠），iframe allow 含 autoplay，移动端 Bilibili 播放器自动播放
- 修复方案（js/main.js）：
  1. 懒加载媒体：accordion 展开时才渲染 iframe/video，收起时清除 DOM 停止播放
  2. iframe allow 移除 autoplay → 改为 `encrypted-media; fullscreen`
  3. Bilibili URL 追加 `&autoplay=0` 参数
  4. Feature Showcase 视频改为懒加载（点击时才设 src），默认 muted=true，用户点击播放后取消静音
  5. Feature 视频 preload 改为 none（原为 metadata）

## Accordion 展开自动滚动优化（全站统一）
- 问题：Internship / Projects 切换 accordion 时，新展开模块位置偏移，用户需手动滚动
- 修改文件：js/main.js
- 新增 scrollToAccordionHeader(element, customOffset) 通用辅助函数：
  - 使用 getBoundingClientRect 计算目标位置
  - 桌面端 offset=28px，移动端 offset=72px（含 56px 导航栏高度）
  - 支持 customOffset 参数自定义偏移
  - 智能跳过：header 已在视口顶部附近时不触发多余滚动
  - targetY clamp 到 0 防止超出页面顶部
- 新增 accordionAnimating 全局锁：防止快速连点导致定时器重叠
- 统一交互模式（Internship + Projects 完全一致）：
  1. 点击 → 立即关闭所有模块（含视频清理）
  2. 200ms 延迟等待 CSS 收起动画完成 ~80%（ease-out-expo）
  3. 展开新模块 + 懒加载媒体 + smooth scroll 到 header
- 200ms 延迟比原 150ms 更准确：布局基本稳定后再计算滚动位置
- 关闭已展开模块时不触发滚动（仅展开新模块时滚动）
- Others 页面无 accordion 交互，无需处理
